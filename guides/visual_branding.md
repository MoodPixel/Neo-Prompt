# Neo Prompt logo and browser icon

Neo Prompt includes its own locally hosted brand assets:

- `neo_prompt/ui/assets/neo-prompt-mark.svg` — the square Neo-family N mark, used in the app sidebar and as the browser SVG favicon.
- `neo_prompt/ui/assets/neo-prompt-logo.svg` — a horizontal wordmark for approved screenshots and project presentation.
- `neo_prompt/ui/assets/favicon.ico` — a multi-size legacy browser tab icon fallback.

The app tab is titled **Neo Prompt — Creative Language Studio**. All assets are local to Neo Prompt; Neo Spaces and other apps are not installed or contacted to render them. The design uses the Neo-family deep navy, violet and cyan appearance while preserving Neo Prompt's distinct product identity.

Replace only with approved visual assets before publishing. Keep SVG and ICO references in `neo_prompt/ui/index.html` synchronized and check icon visibility on your Windows browser after a hard reload. Neo Prompt v1.0.0 uses no remote fonts or CDN art assets. Screenshots can be included in the README once owner-provided, privacy-reviewed captures exist.
